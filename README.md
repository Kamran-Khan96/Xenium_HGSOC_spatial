# Xenium_HGSOC_spatial

This repository contains representative Python and R scripts used in the analysis accompanying our study of 122 treatment-naïve high-grade serous ovarian cancer (HGSOC) samples profiled using the 10X Genomics Xenium in situ spatial transcriptomics platform with a targeted 480-gene panel.

The study investigated the associations between tumour-intrinsic gene expression, the spatial composition of tumour-neighbouring cell populations, and overall survival (OS).

The code provided here illustrates the key analytical workflows used throughout the study, including data processing, spatial neighbourhood analyses, survival analyses, visualisation, and downstream statistical analyses. These scripts are intended as representative examples to facilitate reproducibility and adaptation for similar spatial transcriptomic datasets.

**Repository contents**
1. Python scripts – Spatial data processing, neighbourhood analyses, and cell-level analyses.
2. R scripts – Statistical analyses, survival modelling, visualisation, and downstream data analyses.

**Notes**
1. This repository contains representative analysis scripts rather than the complete end-to-end analysis pipeline.
2. Patient-level data are not included due to ethical and privacy restrictions.
3. The scripts may require modification to accommodate different Xenium datasets, annotation schemes, or directory structures.
